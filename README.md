# CineVault

CineVault is an independent movie-discovery website prototype with a premium, dark cinematic interface.

## Included features
- Responsive desktop and mobile layout
- Curated sample movie catalogue
- Search by title, genre, language and description
- Genre filters and sorting
- Movie detail modal
- Local watchlist using browser local storage
- About, Privacy and Terms starter pages
- No API key or paid service required

## Files
- `index.html` — homepage structure
- `style.css` — visual design and responsive layout
- `movies.js` — sample movie catalogue
- `script.js` — search, filters, modal and watchlist
- `about.html`, `privacy.html`, `terms.html` — information pages

## Important content and licensing note
The catalogue is a manually curated demonstration dataset. Poster-style artwork is generated with CSS; it is not official movie poster artwork. Before monetising the site, obtain appropriate rights or permissions for any third-party movie data, artwork, logos, fonts, analytics or advertising services. The privacy and terms pages are starter templates and must be reviewed and completed with the site owner's real contact details and actual data practices.

CineVault is a discovery guide only. It does not host, stream or provide downloads of films.

## Deployment
Upload the files to the root of the connected GitHub repository and allow the connected Cloudflare deployment to rebuild.
